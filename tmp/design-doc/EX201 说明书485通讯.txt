1.序言 
本书对 EX-201S SERIES 上标准搭载的 RS-485 通信功能的规格以及其使用方法进行
了讲述。 
关于布线、设置及使用方法，有另外讲述的本设备主体的操作说明书，使用前请务
必一起阅读。 
 
2.向〔基于数字通信的控制〕的切换 
 
EX-201S SERIES 已在出厂的时刻设定为〔基于模拟输入的控制〕 。要设定为〔基
于数字通信的控制〕时，请在最初按照本书的下述记载，将 切换到“数字(0)” 。
此外，返回到〔基于模拟输入的控制〕时，请再次切换到“模拟(1)” 。 
 
阀门开闭输入(模拟信号)为“全打开”或“全关闭”时，与 流量设定方法 的设
定无关，按此进行。只有“控制”时，如下页所示，动作根据流量设定方法 的设
定切换。 
另外，流量控制范围其满刻度在 2～100%范围内，2%以下的设定不被保障。

3.基本规格 
同步方式 起停同步 
传送速度※ 9,600 bps 
起始位（Start Bit） 1 比特 
数据长 8 比特 
停止位 1 比特 
奇偶性※ 无 
传送方式 3 线式半双重 
绝缘 通信-控制回路间 :非绝缘 
通信-电源间   : 非绝缘 
通信 ID 设定 根据本机器上面开关 
            ※如机体贴付标签 OPTION 栏有备注内容的话按此进行 
 
针对本机器各个体，使用机器上面的开关 SW1·2，设定通信 ID(01～99)｡此时，
请注意各个体之间没有重复，分别具有唯一性。 
 
将电脑或 PLC 等用户系统等视为主盘（Master） ，将本机器各个体视为从盘
（Slave） ，通信通过主盘发送指令电文而开始，通过从盘回复响应电文而结束。
主盘和各从盘因为共享电文发送接收通道，为了不让电文发生冲突，请按照本步
骤操作。

4.电文构成 
･指令电文 
从主盘发往本设备的指令电文，请设置为如下例所示的构成。 
 
STX 通信 ID 指令 数据 检查和 ETX 
@ 0 0 1 W V S S 1 5 5 CR 
40H 30H 30H 31H 57H 56H 53H 53H 31H 35H 35H 0DH 
 
STX 
 
本机器无条件将 STX 识别为电文的开端。 
“@(40H)” 。固定长 1 字节。 
通信 ID 指定接收地址的本机器的通信 ID。 
“001”～“009” 。固定长 3 字节。 
指令 指定标示指令类别的字符串。固定长 4 字节。 
详情请参照下章。 
数据 因为指令类别长度可变。也有无(0 字节)的指令｡详情请参照下章。 
检查和 从 STX 到数据逐个加算，指定将结果的后两位（16 进制表示）分
别转换为 ASCII 代码之物。固定长 2 字节。※参照下述 
ETX 表示电文的末尾。 “CR(0DH)” 。固定长 1 字节。 
 
※检查和计算例 
例如，当为上述指令的电文时，为下述所示。 
40H + 30H + 30H + 31H + 57H + 56H + 53H + 53H + 31H = 255H 
(STX)      (通信 ID)           (指令)          (数据)(检查和)

･响应电文 
本机器，当自身设定的通信 ID 与用指令电文指定的通信 ID 一致时，按照以下举
例所示的构成回复响应电文。 
 
STX 通信 ID 指令 结束代码 数据 检查和 ETX 
% 0 0 1 R V S S O K 1 C F CR 
25H 30H 30H 31H 52H 56H 53H 53H 4FH 4BH 31H 43H 46H 0DH 
 
 
STX “%(25H)” 。固定长 1 字节。 
通信 ID 这是发送源的本机器的通信 ID。固定长 3 字节。 
指令 是包含在指令电文中的标示命令类别的字符串。 
详情请参照下章。固定长 4 字节。 
结束代码 是表示对应指令电文的结果的字符串。 
“OK”或“NG” 。固定长 2 字节。 
数据 利用指令类别或结束代码可变长度。也有无(0 字节)的指令或带有
符号(+或-)的指令。 
详情请参照下章。 
检查和 从 STX 到数据逐个字节加算，将结果的后两位（16 进制表示）分
别转换为 ASCII 代码之物。固定长 2 字节。※参照前页 
ETX 表示电文的末尾。 “CR(0DH)” 。固定长 1 字节。 
 
※检查和与指令电文具有相同的计算方法。

5.指令详细内容 
对于本机器可执行的指令如下所示。此外，对于使用了此处所示指令以外的指令
时的动作，我公司概不负责。 
 
 
1)RMFS:满刻度流量[尾数部] 的取得 
取得满刻度流量[尾数部] 。 
流量小数点位置[小数点以下位数] 或 流量单位 ，算出满刻度流量而使用。

响应:10 进位 4 位(固定长 4 字节)

取得流量小数点位置[小数点以下位数] 。 
为对应流量单位 ，算出各种流量而使用。 
数据指令:无 
响应:10 进位 1 位(固定长 1 字节) 
0:无､1:1 位､2:2 位､3:3 位 
 
 
3)RFRU:流量单位 的取得 
取得流量单位。 
为对应流量小数点位置[小数点以下位数] ，算出各种流量而使用。 
数据指令:无 
响应:10 进位 1 位(固定长 1 字节) 
0:cc､1:L
