第一章 引言 
1.1 编写目的 
本文定义基于 R7FA4M1AB3CFM 的六路质量流量计控制系统初步软件方案，用于硬件接口核对、
固件开发和联调。控制器作为 RS485 主站，通过 RJ45 线缆向六台 EX-201S 系列质量流量控制器下
发流量设定并读取运行参数，同时管理气路图中的九个外部电磁阀。 
初步方案采用一条 MFC 下行总线、 六个独立通道对象和统一阀门联锁。 设备内部完成流量闭环，
MCU 负责设定、 监测与过程协调。 下文以“已知资料”“设计建议”和“待确认”区分依据与拟定方案； 待
确认项在本章引用资料及第 4.9 节中形成闭环。 
1.2 项目背景 
气路由六条支路经 MFC 汇入混气管，其中五路标注 H2、CH4、N2、O2、CO2，第六路预留。图
中 V1 至 V6 为支路阀，混气管后配置 V7、V8、V9，支持正常输出和排空、校准或测试气体通路。
[S3] 
本项目允许经工艺许可的多路流量同时参与控制。气路组合、压力边界和可运行配方应由工艺确
认，尤其应明确 H2、CH4 与 O2 共用混气管时的许可条件。软件按已批准的通道组合执行，不自动
假定任意气体组合均可运行。 
1.3 阅读人员 
适用人员包括嵌入式软件开发、 硬件设计、 气路与工艺设计、 上位机开发、 测试及现场调试人员。
硬件负责输出极性和断电状态，软件负责时序和异常处理，工艺负责气体组合及实际流量验收条件。 
1.4 术语定义 
术语 说明 
MFC 质量流量控制器；包含传感器、内部比例阀及内部流量闭环。 
RJ45 与 RS485 RJ45 是连接器形式；本设备使用 RS485 电气层和厂家 ASCII 通讯协议。

2.1 项目简介 
六台 MFC 使用独立地址接入同一条半双工总线， MCU 逐台访问。软件维持设定流量、实际流
量、 气体类型、 满量程、 内部阀状态、 设备报警和通讯状态。 外部 V1 至 V6 与对应 MFC 成对管理，
V7 至 V9 由整机通路状态统一管理。

2.2 设计目标 
功能项 初步设计要求 
参数读取 
读取六路实际流量、设定值、气体类型、量程、小数位、单位、流量基准温度、内部阀
状态及设备报警。 
流量控制 
每路独立启停和设定；写入后回读确认；对超量程、未就绪、未获许可及低于可控范围
的非零设定返回明确错误。 
通路控制 
统一管理 V1 至 V9。正常模式中 V7 与 V9 按资料要求开启，V8 关闭； 校准或排空通
路按第 4.4 节执行。 
异常处理 
对超时、校验错误、设备 NG、流量持续偏差、设备报警和手动关闭分别处理，禁止把
无效流量当作零流量。

4.2 EX201 通讯协议模块 
4.2.1 总线与电文格式 
下行使用 EX201 自定义 ASCII 协议，默认 9600 bps 、8 数据位、无校验、 1 停止位；若设备  
OPTION 铭牌另有标注，以铭牌为准。主站同一时刻只允许一笔未完成事务。地址拨码建议分别设为 
01 至 06，报文编码为 001 至 006。[S1 印刷页 5 至 7] 
方向 字段顺序 说明 
请求 @ + ID(3) + CMD(4) + DATA(n) + SUM(2) + CR @ 为 0x40；数据长度由命令决定；
CR 为 0x0D。 
响应 % + ID(3) + CMD(4) + OK/NG(2) + DATA(n) + SUM(2) + CR % 为 0x25；写命令通常无数据，但
仍应收到结束代码及校验。 
校验 SUM = 所有起始符至数据字节之和的低 8 位 
将结果转换为两位大写十六进制 
ASCII；不包含 SUM 自身及 CR。 
 
接收采用“找 % → 累计至 CR → 验证长度、校验、地址、命令与结束代码 → 解析数据”的状态
机。缓存初值可取 64 字节；过长帧、无效字符、串口溢出和未结束帧均丢弃并记录。发送方向在最
后一个停止位真正发完后切回接收，不能在发送缓冲区空时提前切换。

4.2.3 流量换算与设定事务 
设备流量  = 带符号尾数  × 10^(− 小数位 )。若 RFRU=0，界面按  cc/min 或 mL/min 显示；若  
RFRU=1，按 L/min 显示。统一到 mL/min 时，L/min 数值乘 1000。显示必须同时保留 RFRC 的基
准温度条件，不能把不同基准条件的体积流量直接当成相同计量条件。 
示例：RMFS=1000、RDPP=1、RFRU=0 时，满量程为 100.0 mL/min 。用户设定 25.0 mL/min ，对
应 WSFD 数据 0250。 换算使用整数定点或受控舍入， 先检查有限值与上下界， 再格式化为固定四位
数字。 
零设定允许用于停止； 非零常规设定限定在设备 2% 至 100% F.S. 可控范围内。 手册指出 1% F.S. 
以下按全关闭处理，而 2% 以下控制不保证，因此界面拒绝 0 与 2% F.S. 之间的非零设定，不能静
默修正为其他值。[S1 印刷页 3、13]

4.2.5 轮询与异常重试 
轮询采用轮转队列：RCFR 为快速项，RALM、RCVS、RSFD 为慢速项，量程与气体参数在初始化、
维护变更或重连时读取。 停止请求优先于普通写入， 普通写入优先于低频查询； 同一路待发送设定可
合并为最新值，已开始的事务必须有明确结束结果。 
9600 bps、8N1 下每字节约 1.042 ms。一次 RCFR 请求为 11 字节，按“符号加四位数字”的响应
为 18 字节，纯传输约 30.2 ms ；六路至少约 181 ms ，尚不含从站处理、方向切换和慢速查询。建
议响应超时初值 150 ms、帧间余量 5 ms、只读重试最多 1 次，现场测量后统一调整。 
单通道建议连续 3 次事务失败置离线， 快速数据超过 3 s 未更新置陈旧； 这些是可调联调初值，
不是手册保证。 离线设备进入低频探测， 不能持续阻塞健康通道。 在线运行通道失去有效数据时， 按
整机故障策略停机，不等到无限重试。 
写入超时后先回读目标参数再决定是否重发； 对 ZERO 不自动重试。 超时后清空旧事务并设置恢
复窗口， 在确认接收空闲后再发新请求。 协议没有事务序号， 相同地址和命令的迟到响应可能无法区
分，必须通过受控串行、清理迟到帧和回读最终值降低歧义。

4.3.2 启动与停止 
启动前确认参与通道已启用、气体和量程匹配、预热完成、无锁定故障、手动许可有效、下游通

件同步机制，不能用“批量写成功”代替同时生效。 
正常停止先关闭参与支路的外部阀，同时排队发送 WVSS=2 和 WSFD=0000，按工艺确认的延时
